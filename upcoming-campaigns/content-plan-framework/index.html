Template · Reusable

Content Plan Framework

A fill-in-the-blanks template any campaign can follow. The sections mirror how our campaign pages are already built, so a new campaign can go from idea to a reviewable page quickly.

How to use this

1 · Copy the sections

Work through all 14 in order. Each has a short prompt and blank fields.

2 · Mark what's decided

Label anything not yet decided as Proposed. Leave blanks blank rather than guessing numbers or dates.

3 · Use the example

The green box on each section shows how Write Your Own Rules fills it, using only what's already on its page.

4 · Review before sharing

Run the compliance and approvals sections before anything goes to leadership or publishes.
